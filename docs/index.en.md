# snAIl — the robot that teaches young people robotics and AI

![The snAIl robot prototype](assets/images/snail.jpg){ width="480" align=right }

**snAIl** is a snail-shaped educational robot built to teach young people aged **8 to 17** four skills that shape the future:

- **robot control**;
- **artificial intelligence** (embedded on the robot);
- **computer vision**;
- **path planning**.

The project is carried by a **non-profit association** (being created), so that cost is never the barrier between a young person and robotics.

## Two tracks, one robot

| Track | Age | Language |
|---|---|---|
| **Visual blocks** | Ages 8–12 | Snap-together blocks, in the style of Scratch |
| **Python** | Ages 13–17 | Real Python, the language of AI research |

Skills stack up step by step: **drive → sense → see → plan → decide**. The destination of every track is **autonomy**: a robot that perceives, decides and acts on its own, powered by the students' code.

## For teachers

We develop **[ready-to-teach lessons](lecons/index.md)**, published on this site: objectives, materials and a step-by-step plan, so you can prepare each session in advance and run it in class with the robot.

Browse the **[workshop catalogue](ateliers/index.md)**: path finding, reinforcement learning, genetic algorithms, localization, digit recognition — and soon LiDAR, 3D vision and voice AI on the robot.
