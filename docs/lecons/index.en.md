# The lessons

Every lesson is **ready to teach**: objectives, materials, a minute-by-minute plan. The teacher prepares the session in advance on this site, then runs it in class with the students and the robot. No robotics degree needed.

## Blocks track (ages 8–12)

Snap-together block programming, in the style of Scratch — no typing, no syntax errors, pure logic.

- [Lesson B1 — Discovery: make snAIl move](blocs-01-decouverte.md)
- *More lessons coming: sensors, reactions, first algorithms…*

## Python track (ages 13–17)

Real Python, on the same robot: motors, sensors, then computer vision and planning.

- [Lesson P1 — First steps in Python with snAIl](python-01-premiers-pas.md)
- *More lessons coming: 3D camera, LiDAR, autonomy…*
