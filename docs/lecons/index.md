# Les leçons

Chaque leçon est **clé en main** : objectifs, matériel, déroulé minute par minute. L'enseignant prépare la séance à l'avance sur ce site, puis la mène en classe avec les élèves et le robot. Pas besoin d'être roboticien.

## Parcours blocs (8–12 ans)

Programmation par blocs à emboîter, dans l'esprit de Scratch — pas de clavier, pas d'erreur de syntaxe, que de la logique.

- [Leçon B1 — Découverte : faire bouger snAIl](blocs-01-decouverte.md)
- *D'autres leçons arrivent : capteurs, réactions, premiers algorithmes…*

## Parcours Python (13–17 ans)

Du vrai Python, sur le même robot : moteurs, capteurs, puis vision par ordinateur et planification.

- [Leçon P1 — Premiers pas en Python avec snAIl](python-01-premiers-pas.md)
- *D'autres leçons arrivent : caméra 3D, LiDAR, autonomie…*
